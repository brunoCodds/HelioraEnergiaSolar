COMO ADICIONAR AS FOTOS
========================
Basta salvar os arquivos de imagem NESTA pasta (images/) usando exatamente
os nomes abaixo. O site já está com os espaços reservados — assim que você
colocar o arquivo com o nome certo, a foto aparece automaticamente no lugar
do quadro amarelo/cinza de aviso.

Formato recomendado: .jpg, otimizado para web (até ~300kb cada).

Dica: você pode reaproveitar as fotos que já tinha no site antigo — os nomes
acima são só sugestões, o importante é que cada arquivo tenha o nome exato
listado. Se quiser trocar alguma foto de lugar, é só renomear o arquivo.

Nenhuma imagem aqui ainda? Sem problema — enquanto os arquivos não existirem,
o site mostra um quadro de aviso no lugar, só para você (o visitante do site
nunca vê nada quebrado feio, mas o ideal é subir as fotos reais antes de publicar).
